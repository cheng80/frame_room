작업 공간 · 어디서 무엇을 하나요?

왼쪽 라이브러리, 중앙 캔버스와 아래 재생 순서, 오른쪽 속성을 함께 사용합니다. 자료 준비 도구는 편집기 위에 창으로 열립니다.

현재 후보와 현재 슬롯 구분하기

후보는 추출한 프레임의 목록입니다. 슬롯은 그 후보를 동작의 재생 순서에 넣은 자리입니다. 같은 후보를 여러 슬롯에 넣고 서로 다른 시간과 변형을 줄 수 있습니다.

  1. 왼쪽 동작 탭에서 편집할 동작을 선택하고, 후보 탭에서 사용할 프레임을 찾습니다.
  2. 후보를 누르면 중앙의 후보 원본을 봅니다. 순서에 추가 버튼을 눌러야 동작에 들어갑니다.
  3. 아래 재생 순서의 슬롯을 선택하면 오른쪽 슬롯·픽셀 속성으로 편집합니다. 중앙의 재생 순서와 후보 원본 전환을 확인하세요.

후보 번호는 목록의 순번입니다. 품질 순위나 앱의 추천 점수가 아닙니다.

도구 창과 좁은 화면 사용하기

상단의 자료 가져오기·외형 기준·AI 동작 생성·프레임 나누기·크기·발 정렬을 열어 필요한 작업만 수행합니다.

  1. 편집할 후보나 슬롯을 선택한 뒤 필요한 도구를 엽니다. 프레임 나누기와 정렬은 메인 선택에 연결된 이미지·후보를 먼저 보여줄 수 있습니다.
  2. 도구의 이미지와 설정은 따로 스크롤합니다. 좁은 창에서는 미리보기/설정 또는 후보 보기/좌표·배율 버튼으로 영역을 전환합니다.
  3. 편집기로 돌아가기 또는 닫기를 눌러 메인 화면으로 돌아옵니다. 좁은 메인 화면은 라이브러리·캔버스·속성 버튼으로 전환합니다.

도구를 닫는 동작은 저장 버튼을 대신하지 않습니다. 미저장 표시와 각 도구의 초안 적용·저장 버튼을 확인하세요.

다음 작업에서 이어 하기

편집기 위의 다음 작업 버튼은 선택 동작에서 남은 첫 작업과 개수를 표시합니다. 오른쪽 다음 작업 탭 안에서 목록과 자동 검사 결과를 확인합니다. 페이지 바깥으로 길게 스크롤하지 않습니다.

  1. 기준 연결, 사용 후보·앵커 승인, 미저장 초안 등 현재 상태를 확인합니다. 사용하지 않는 후보의 승인은 선택 동작의 필수 작업에 넣지 않습니다.
  2. 작업 버튼을 누르면 관련 후보·슬롯·기준·정렬·저장·출력 도구로 이동합니다. 자동 검사 결과에서는 해당 프레임·도구로 이동을 사용합니다.
  3. 변경 후에는 먼저 저장하고 후보·앵커·동작을 다시 확인하세요. 충돌이 있으면 저장 충돌 해결부터 진행합니다.

수동 승인 조건을 만족해도 자동 경고가 남을 수 있습니다. 자동 검사는 예술적 품질을 보장하지 않습니다.

제작 이력과 후보 묶음

후보 탭은 기록으로 연결된 추출 실행별로 후보를 묶습니다. 원본 자료, 생성 제공자·모델과 작업 ID, 추출 실행, 클립 사용처를 확인할 수 있습니다.

  1. 추출 실행 묶음을 펼치고 원본을 눌러 프레임 나누기에서 해당 자료를 확인합니다.
  2. 후보의 출처·사용처를 펼치면 원본에서 파생된 경로와 추출 영역이 나옵니다. 같은 후보를 반복 사용한 슬롯도 각각 표시합니다.
  3. 동작 이름·슬롯 이동 버튼을 누르면 그 동작의 해당 슬롯이 선택됩니다. 아래 생성·추출 실행 기록에서 과거 실행도 확인합니다.

기록으로 연결할 수 없는 실행은 추출 실행 연결 미기록으로 표시합니다. 파일명·시각·번호만으로 계보나 추천 순위를 만들지 않습니다.

FRAME ROOM / 02

프로젝트와 자료 가져오기

프로젝트에는 원본 이미지와 편집 이력을 함께 보관합니다. 가져올 파일의 역할과 시트 형태를 먼저 정합니다.

새 프로젝트 열기

프로젝트 목록에서 새 프로젝트를 만들거나 기존 프로젝트를 엽니다. 기본 셀 크기는 출력 프레임의 작업 공간이며, 가져올 이미지의 크기와 같을 필요는 없습니다.

  1. 새 프로젝트를 누르고 프로젝트 이름·캐릭터 이름을 입력합니다.
  2. 기본 셀 너비와 높이를 정해 프로젝트 만들기를 누릅니다. 잘림을 피할 충분한 공간을 고려하세요.
  3. 프로젝트를 다시 열 때 목록의 저장 버전을 확인합니다. 사본이 필요하면 이력·백업의 새 프로젝트로 복제를 사용합니다.

파일 선택 후 가져오기 실행하기

파일을 선택하거나 파일바에 놓는 것은 업로드 준비입니다. 선택한 파일을 가져오는 버튼을 눌러 등록을 완료합니다.

  1. 자료 가져오기에서 PNG·WebP를 하나 이상 선택합니다. 선택한 파일 목록과 화면에 표시된 파일당 크기 한도를 확인합니다.
  2. 자료 역할을 편집할 원본·외형 기준·스타일 참조·자세 참고 중에서 고르고, 가져오기 형태를 개별 이미지·규칙 격자 시트·아틀라스/수동 영역 중에서 고릅니다.
  3. 선택한 파일 가져오기를 누른 뒤 등록된 자료의 크기·역할·출처·알파 정보를 확인합니다. 시트를 프레임으로 나누는 작업은 프레임 나누기에서 진행합니다.

가져오기가 잠겨 있으면 현재 편집 초안을 먼저 저장하세요. 자료 역할을 외형 기준으로 고르는 것만으로 기준 승인이 끝나지는 않습니다.

출처와 투명도 읽기

원본, 배경 제거 결과, 추출 프레임은 자료의 출처 정보로 구별합니다. 파일명이나 이미지 모양만 보고 AI 생성 여부를 판단하지 마세요.

  1. 자료 카드에서 가져온 원본·AI 생성 원본·배경 제거 결과·추출 프레임 등의 출처 라벨을 읽습니다.
  2. 투명·반투명·불투명 픽셀 수를 확인합니다. 실제 알파 포함 표시는 투명 픽셀이 있다는 뜻이지 경계 품질이 완벽하다는 뜻은 아닙니다.
  3. 불투명 이미지라면 원본을 보존한 채 프레임 나누기의 배경 정리에서 별도 결과를 만들고 검수합니다.

이미지 안에 그려진 체크무늬는 실제 투명도가 아닙니다. 복잡한 배경은 단색 제거만으로 깨끗하게 정리되지 않을 수 있습니다.

외형 기준 · 지킬 특징을 먼저 정하기

외형 기준은 캐릭터의 정체성을 정합니다. 스타일과 자세 이미지는 별도 보조 참조로 선택합니다.

외형 초안 만들기

외형 탭에서 큰 이미지와 함께 얼굴·의상·장비·팔레트 등 유지할 특징을 기록합니다.

  1. 외형 기준 이미지를 선택하고 큰 미리보기로 기준에 사용할 이미지가 맞는지 확인합니다.
  2. 고정 특징, 변경해도 되는 특징, 스타일에서 가져오면 안 되는 특징을 적고 기준 방향을 선택합니다.
  3. 새 기준 초안 저장을 눌러 기준 버전을 만듭니다. 승인된 기존 기준을 바꾸려면 새 초안으로 저장합니다.

참조 역할을 나누고 승인하기

스타일·자세 선택이 외형 기준을 대신하지 않습니다. 승인도 사용자가 기준을 확인한 뒤 수행하는 별도 단계입니다.

  1. 참조 탭에서 필요한 이미지에 스타일 또는 자세 역할을 체크하고 새 기준 초안 저장을 누릅니다.
  2. 승인 탭에서 저장된 기준 버전과 고정 특징을 읽고 외형·역할·방향을 확인했다는 항목을 체크합니다.
  3. 이 기준 승인을 누릅니다. 동작에서는 속성의 동작에 사용할 승인 기준으로 해당 버전을 연결할 수 있습니다.

후보 검수의 나란히 비교할 승인 기준은 비교 화면만 바꿉니다. 동작 자체의 기준 연결은 슬롯 속성에서 변경하세요.

FRAME ROOM / 04

AI 동작 생성 · 기준을 보며 요청하기

승인된 외형 이미지와 고정 특징을 옆에 두고 동작을 설명합니다. 생성 요청은 새 후보 생성 버튼을 눌렀을 때만 접수됩니다.

요청 작성과 연결 확인

생성 연결에는 제공자·모델·연결 상태와 지원하는 옵션이 표시됩니다. 연결 준비 표시는 실제 생성 성공이나 남은 사용량을 보장하지 않습니다.

  1. 외형 기준이 승인되어 있는지 확인하고 동작과 포즈 설명에 방향·행동·유지할 특징을 적습니다.
  2. 생성 범위와 요청 프레임 수, 배경을 정합니다. 예를 들어 6은 요청 프레임 수의 예시값이며 정확히 여섯 프레임이 추출된다는 보장은 없습니다.
  3. 생성 연결을 펼쳐 제공자·모델과 준비 상태를 확인합니다. 설정을 보관하려면 설정을 초안에 적용한 뒤 상단 저장을 누르고 새 후보 생성을 요청합니다.

비활성화된 해상도·품질 옵션은 해당 연결이 지원하지 않는 항목입니다. 이 화면에는 로그인 입력창이 없으며 연결 상태 확인만 제공합니다.

배경과 한 프레임 재생성

투명 배경 요청은 실제 알파를 보장하지 않습니다. 한 프레임 재생성도 기존 슬롯을 자동으로 교체하지 않습니다.

  1. 녹색·흰색·마젠타 또는 지원되는 경우 투명 배경 요청을 선택합니다. 결과에서는 알파와 캐릭터 가장자리를 다시 확인합니다.
  2. 특정 후보를 다시 만들려면 생성 범위를 한 프레임 재생성으로 바꾸고 재생성할 프레임을 직접 선택합니다. 유지할 자세와 고칠 부분을 프롬프트에 적습니다.
  3. 작업 결과를 자료와 후보로 확인하고 필요하면 다시 추출합니다. 사용할 결과를 검수한 뒤 선택 슬롯을 이 후보로 교체하거나 순서에 추가합니다.

예시의 6은 요청값이고, 후보 7~12는 해당 예제 프로젝트의 목록 번호입니다. 두 숫자는 자동 대응이나 추천 규칙을 뜻하지 않습니다.

생성 중·중단 후 확인하기

도구 창을 닫아도 실행 환경이 유지되는 동안 작업은 계속됩니다. 앱을 실행한 로컬 서비스 자체가 종료되면 작업도 중단될 수 있습니다.

  1. 작업 센터에서 대기 중·처리 중·완료·승인 대기 상태를 확인합니다.
  2. 취소가 필요하면 작업 취소 요청을 누릅니다. 외부 요청의 즉시 중단이나 과금 중단까지 보장하는 버튼은 아닙니다.
  3. 외부 접수 결과 불명이 표시되면 같은 생성을 바로 반복하지 말고 기존 결과와 오류를 확인합니다. 앱은 이 상태에서 자동 재전송하거나 다른 유료 제공자로 전환하지 않습니다.

프레임 나누기 · 원본에서 후보 만들기

추출된 후보는 편집할 재료입니다. 좋은 포즈를 자동으로 추천하거나 재생 순서에 자동 배치하는 기능은 아닙니다.

원본과 추출 방식 선택하기

메인에서 선택한 프레임의 원본이 먼저 열릴 수 있습니다. 처리할 이미지 목록에서 다른 자료를 직접 고를 수도 있습니다.

  1. 프레임 나누기를 열어 처리할 이미지와 큰 원본 미리보기가 맞는지 확인합니다.
  2. 한 장이면 전체 이미지, 규칙 시트면 행·열을 정하는 규칙 격자, 분리된 덩어리면 연결 성분 자동 추출, 직접 범위를 정하려면 수동 영역을 선택합니다.
  3. 미리보기 영역을 확인하고 공통 배율 그룹을 정한 뒤 프레임 후보 추출을 누릅니다. 완료 후 라이브러리 후보 탭에서 실제 결과를 확인합니다.

연결 성분에서는 작은 조각과 분리된 장비를 확인하세요. 추출 완료나 영역 추출 표시는 외형 검수 승인이 아닙니다.

수동 영역과 메타데이터 다루기

수동 영역은 좌표 입력으로 정의합니다. 미리보기에 영역을 마우스로 그리는 기능으로 설명하지 않습니다.

  1. 왼쪽 X·위쪽 Y·너비·높이를 입력하고 영역 추가를 누릅니다. 또는 아틀라스 메타데이터 가져오기로 Aseprite JSON이나 runtime.json을 읽습니다.
  2. 목록에서 두 영역 이상을 체크해 선택 영역 병합으로 둘러싸는 하나의 영역을 만듭니다. 불필요한 영역은 제외합니다.
  3. 잘못 편집했으면 영역 편집 되돌리기를 누릅니다. 순서와 경계를 확인한 뒤 추출하며, 다른 이미지를 선택하면 현재 영역 목록과 되돌리기 내역이 초기화됩니다.

이미지 경계를 벗어나거나 지원하지 않는 메타데이터는 오류로 표시됩니다. 같은 파일의 좌표인지 확인하세요.

배경 정리와 잘린 결과 처리하기

배경 정리는 별도 결과를 만듭니다. 원본을 덮어쓰지 않으므로 결과를 확인하고 다음 처리 이미지를 직접 선택합니다.

  1. 설정의 배경 정리를 펼치고 제거할 단색 또는 모서리에서 자동 추정을 선택합니다.
  2. 색 허용 오차를 조절해 배경 제거 결과 만들기를 누릅니다. 완료되면 처리할 이미지에서 새 결과를 골라 가장자리와 장비가 남았는지 확인합니다.
  3. 추출 후보 자체에서 팔·무기 등이 잘렸다면 원본으로 돌아가 행·열 또는 수동 영역을 넓혀 다시 추출합니다. 후보는 온전한데 출력 셀에서 잘리면 정렬·변형을 점검합니다.

복잡한 배경이나 그려진 체크무늬는 균일한 단색 제거에 적합하지 않습니다. 슬롯 픽셀 보정 또는 새 이미지 준비를 고려하세요.

크기·발 정렬 · 같은 기준으로 맞추기

자세마다 몸 전체 높이를 억지로 같게 맞추지 않습니다. 공통 배율과 각 프레임의 발·루트 앵커로 위치를 정합니다.

출력 셀과 공통 배율 정하기

그룹의 셀과 배율 변경은 그 그룹의 여러 후보에 영향을 줍니다. 화면 확대 배율과 출력에 쓰는 공통 배율을 구분하세요.

  1. 정렬할 후보를 고르고 공통 배율·셀 탭에서 셀 너비·높이·안전 여백과 목표 앵커를 확인합니다.
  2. 원본 크기 유지로 1×를 사용하거나, 몸의 위쪽·아래쪽 Y와 목표 체고를 입력해 확인 체크 후 공통 배율 계산·적용을 누릅니다.
  3. 다른 자세와 장비가 셀 안에 들어오는지 확인합니다. 그룹을 바꾼 뒤 관련 후보의 앵커를 다시 확인하고 승인합니다.

512px 정렬 프리셋은 셀과 목표 앵커를 바꾸는 편의 설정입니다. 모든 이미지의 잘림을 자동 해결하는 기능은 아닙니다.

발 앵커 또는 공중 루트 승인하기

자동 발 후보 계산은 픽셀을 바탕으로 위치를 제안합니다. 계산만으로 수동 좌표를 덮어쓰거나 앵커를 승인하지 않습니다.

  1. 발·루트 앵커 탭에서 지면/공중을 고르고 원본 이미지 위를 클릭하거나 X·Y 좌표로 기준점을 정합니다.
  2. 자동 발 후보 다시 계산을 사용할 경우 제안 좌표를 확인한 뒤 자동값 적용을 누릅니다. 자동값 적용은 지면 발 앵커이므로 공중 자세는 루트 위치를 별도로 확인합니다.
  3. 의도한 이동을 조절해 자세의 움직임을 유지하고 이 후보 앵커 승인을 누른 뒤 저장합니다. 동작 재생으로 발 흔들림과 공중 궤적을 확인합니다.

이미지의 앵커 편집 영역에 포커스를 두면 방향키는 1px, Shift+방향키는 10px씩 이동합니다.

동작 편집 · 순서·시간·픽셀

재생 순서에 들어간 각 자리를 슬롯이라고 합니다. 같은 후보를 반복해 사용해도 시간·변형·픽셀 보정은 슬롯별로 편집할 수 있습니다.

동작 만들고 순서 구성하기

후보를 선택해 미리보기로 보는 것과 동작에 추가하는 것은 다릅니다. 후보 원본 위의 안내와 아래 재생 순서를 함께 확인하세요.

  1. 라이브러리의 동작 탭에서 새 동작을 열고 이름을 입력해 동작 만들기를 누릅니다. 슬롯 속성에서 사용할 승인 기준을 확인합니다.
  2. 후보 탭에서 프레임을 골라 선택 후보를 순서에 추가합니다. 같은 후보를 다시 추가하거나 기존 슬롯을 복제해 반복 포즈를 만듭니다.
  3. 아래 슬롯을 선택해 앞으로/뒤로 이동하거나 순서에서 제거합니다. 다른 후보로 바꾸려면 대상 슬롯을 선택한 뒤 후보를 고르고 검수 속성의 선택 슬롯을 이 후보로 교체를 사용합니다.

순서에서 제거는 그 슬롯만 없앱니다. 후보와 원본은 남습니다. 후보 교체는 해당 슬롯의 변형과 픽셀 보정을 초기화하므로 적용 후 다시 확인하세요.

시간과 재생 확인하기

기본 FPS는 FPS를 따르는 슬롯에 적용됩니다. 직접 지정한 밀리초는 별도 값으로 유지됩니다.

  1. 슬롯 속성에서 기본 FPS와 반복 재생 여부를 정합니다. 반복을 끈 동작은 끝에서 마지막 프레임을 유지합니다.
  2. 아래 슬롯 표시 시간을 기본 FPS 따름 또는 직접 지정으로 고르고 표시 시간(ms)을 조절합니다. 숫자 입력은 다른 곳을 누르거나 Enter로 확정합니다.
  3. 재생·일시 정지·이전·다음으로 흐름을 확인합니다. 0.25×·0.5×·1×·2× 미리보기 속도와 보기 배경을 바꿔 검사합니다.

미리보기 속도, 맞춤·1:1·게임 128px, 보기 배경은 화면 확인용입니다. 출력 시간이나 셀 크기를 바꾸려면 실제 슬롯·그룹 설정을 수정하세요.

변형과 픽셀 보정하기

슬롯 속성에서 이동·배율·회전·기울기·반전·변형 중심을 조절합니다. 픽셀 보정은 변형 전 셀 좌표에 적용됩니다.

  1. 수정할 슬롯을 고르고 이동·변형 수치를 조절합니다. 변형 초기화로 기본 변형으로 돌아갈 수 있습니다.
  2. 픽셀 탭에서 픽셀 펜 또는 알파 지우개를 고릅니다. 캔버스를 누르거나 픽셀 X·Y를 입력해 지정 픽셀에 적용합니다.
  3. 이전·다음 프레임 겹쳐 보기와 기준 비교를 켜서 비교합니다. 잘못된 초안 편집은 되돌리고, 확인한 내용을 저장한 뒤 다시 검수합니다.

편집 캔버스는 빠른 미리보기입니다. 최종 픽셀과 경계는 내보내기의 확정 미리보기·출력 결과에서 확인하세요.

검수 · 승인 표시를 정확히 읽기

수동 승인됨은 승인 버튼으로 기록한 상태입니다. 자동 검사 결과와 분리해서 확인하며, 변경으로 무효화된 승인은 변경 후 재확인 필요로 표시됩니다.

후보를 비교하고 수동 승인하기

라이브러리의 후보는 추출 목록입니다. 예제 화면의 후보 7~12는 assistant가 확인 후 수동으로 승인한 항목이며 앱의 자동 추천·자동 미술 판정 결과가 아닙니다.

  1. 검수할 후보를 고르고 속성의 수동 승인 탭에서 승인 기준과 후보를 나란히 봅니다. 필요하면 비교 배율을 1:1·200%·400%로 바꿉니다.
  2. 외형·의상·장비·방향·알파를 직접 확인해 후보 수동 승인을 누릅니다. 문제가 있으면 이유를 적고 사유 기록·후보 거절을 누릅니다.
  3. 상단 저장으로 상태와 사유를 확정합니다. 후보 숨기기는 목록 표시를 줄이는 기능이며, 숨긴 후보 포함으로 다시 볼 수 있습니다.

승인 대기는 아직 확인해야 한다는 표시입니다. 이미지가 반드시 잘못됐다는 뜻도, 자동으로 고쳐진다는 뜻도 아닙니다.

자동 검사와 동작 승인 나누기

자동 검사는 저장 버전의 픽셀·경계·구조를 검사합니다. 후보·앵커·동작의 수동 승인 조건은 검사 경고와 구별해서 표시합니다.

  1. 먼저 초안을 저장하고 다음 작업 또는 수동 승인 탭의 선택 동작 자동 검사 실행을 누릅니다. 검사 입력 버전과 현재 저장 버전을 비교하세요.
  2. 경고의 해당 프레임·도구로 이동을 눌러 지정 슬롯이나 정렬·픽셀 도구를 엽니다. 셀 넘침은 기록된 방향과 픽셀 수를 보여줍니다. 낮은 알파 경고는 개별 픽셀 좌표가 제공되지 않음을 표시합니다.
  3. 기준·후보·앵커 승인을 마친 후 동작 체크리스트를 확인하고 동작 수동 승인 · 초안에 적용을 누른 뒤 저장합니다. 이후 수정하면 변경 후 재확인 필요가 표시됩니다.
  4. 미저장 초안이나 다른 저장 버전의 보고서는 이전 버전 검사 · 재실행 필요로 표시합니다. 저장 후 자동 검사를 다시 실행하세요.

팀 테두리와 잘림 확인하기

테두리는 미리보기 전용 또는 출력 파일 포함으로 설정할 수 있습니다. 테두리 보기만 꺼도 경계 문제 자체가 해결되지는 않습니다.

  1. 테두리 사용 여부, 팀 이름·색·두께·불투명도·4방향/8방향을 설정하고 포함 범위를 정합니다.
  2. 편집 화면에서 테두리를 꺼 원래 알파와 경계를 검사하고, 테두리를 출력에 넣을 때는 바깥 여백도 확인합니다.
  3. 설정을 저장하고 영향을 받는 동작을 다시 승인합니다. 출력에서 잘림이 보고되면 셀·앵커·슬롯 변형·테두리 두께를 수정한 뒤 재검수합니다.

내보내기 · 저장된 결과 확인하기

출력은 저장된 버전으로 만듭니다. 현재 편집 미리보기와 이전에 만들어 둔 출력 결과가 서로 다를 수 있습니다.

출력 전에 잠긴 이유부터 확인하기

내보내기 설정에는 출력할 동작과 사전 검사 항목이 표시됩니다. 문제가 있으면 해당 도구로 돌아가 수정합니다.

  1. 미저장 초안과 저장 충돌을 해결하고, 출력할 동작을 선택합니다.
  2. 빈 재생 순서·미승인 기준·후보 검수·앵커 승인·동작 검수·표시 시간 안내를 확인합니다. 수정 후 저장하고 필요한 승인을 다시 완료합니다.
  3. 확정 미리보기 만들기로 결과를 확인하거나 게임용 파일 출력을 누릅니다. 실제 출력 과정에서도 파일과 경계를 다시 검사합니다.

막혔을 때 확인할 것

지금 상태를 먼저 확인하면 처음부터 다시 만들지 않아도 됩니다.

후보가 여러 개 생겼는데 앱이 좋은 것을 골라준 건가요?

아닙니다. 후보는 이미지에서 추출한 프레임 목록입니다. 번호도 목록 순번입니다. 직접 비교하고 승인·거절하거나 숨기고, 사용할 후보를 재생 순서에 추가하세요.

예제 후보 7~12에 수동 승인됨이 표시되는 이유는 무엇인가요?

그 예제에서는 assistant가 후보를 확인한 뒤 수동 승인했습니다. 수동 승인됨/approved는 승인 조작으로 기록한 상태이며 앱의 자동 추천이나 미술 품질 판정 결과가 아닙니다.

요청 프레임 수를 6으로 정하면 정확히 여섯 장이 나오나요?

6은 예시 요청값입니다. 생성된 시트의 실제 구성이나 추출 결과 수를 보장하지 않습니다. 원본과 추출 영역을 확인하고 실제 후보 수를 기준으로 동작을 구성하세요.

후보를 눌렀는데 왜 재생되지 않나요?

후보 원본 보기는 재생 순서를 채우지 않습니다. 먼저 동작을 만들고 선택 후보를 순서에 추가하세요. 재생 순서의 슬롯이 있어야 애니메이션이 재생됩니다.

승인 대기가 계속 표시됩니다. 자동 검사를 다시 하면 되나요?

후보·앵커·동작 중 어떤 승인이 필요한지 먼저 확인하세요. 자동 검사는 수동 승인을 대신하지 않습니다. 편집으로 관련 승인이 무효화됐다면 내용을 저장하고 다시 확인한 뒤 승인해야 합니다.

캐릭터나 무기가 잘려 보여요.

먼저 후보 원본을 보세요. 원본 후보부터 잘렸다면 추출 영역을 수정해 다시 추출합니다. 후보는 온전한데 셀에서 잘리면 셀 크기·공통 배율·목표 앵커·슬롯 변형·테두리를 확인하세요. 맞춤은 화면 배율만 바꾸므로 출력 잘림을 고치지 않습니다.

투명 배경을 요청했는데 배경이 남아 있어요.

투명 요청은 결과 알파를 보장하지 않습니다. 자료의 투명 픽셀 수와 경계를 확인하세요. 균일한 단색은 별도 배경 제거 결과를 만들 수 있지만, 그려진 체크무늬나 복잡한 배경은 픽셀 보정 또는 새 이미지가 필요할 수 있습니다.

생성·가져오기·출력 버튼이 비활성화되어 있어요.

미저장 초안·처리 중 상태·연결 상태와 화면 안내를 확인하세요. 생성에는 승인 외형 기준·사용 가능한 연결·프롬프트가 필요하고, 한 프레임 재생성에는 대상 선택도 필요합니다. 출력은 내보내기 설정의 검사 항목을 모두 확인하세요.

기본 FPS를 바꿨는데 어떤 슬롯의 시간은 그대로예요.

직접 지정한 밀리초는 기본 FPS 변경에 따라 바뀌지 않습니다. 해당 슬롯의 슬롯 표시 시간을 기본 FPS 따름으로 바꾸거나 밀리초를 직접 수정하세요.

숨기기나 순서에서 제거가 원본 파일도 지우나요?

후보 숨기기는 목록 표시 상태를 바꾸며, 순서에서 제거는 선택 슬롯을 제거합니다. 후보 원본 파일을 삭제하는 동작은 아닙니다. 숨긴 후보 포함으로 목록에서 다시 찾을 수 있습니다.

저장했는데 출력 화면은 예전 모습이에요.

출력 화면은 선택한 저장 버전으로 만든 결과를 재생합니다. 현재 편집과 다른 버전 안내와 출력 버전을 확인하세요. 최신 편집을 저장·검수하고 새 출력을 만들어 열어야 반영됩니다.

연결이 끊겼을 때 페이지를 바로 새로고침해도 되나요?

미저장 초안이 있으면 가능한 경우 현재 초안을 다운로드하고 로컬 앱 실행 상태와 연결을 먼저 확인하세요. 모든 도구 입력이 복구되는 것은 아닙니다. 브라우저 데이터 삭제는 초안 보관까지 없앨 수 있습니다.

외부 접수 결과 불명이면 다시 생성을 누르면 되나요?

외부에 요청이 접수됐을 수 있어 바로 반복하면 중복 생성이 될 수 있습니다. 작업 상태·기존 산출물·제공자 측 결과를 먼저 확인한 뒤 새 요청 여부를 결정하세요. 앱은 이 상태에서 자동 재전송하지 않습니다.

파일 뷰어에서 이미지 크기나 해시가 다르다고 합니다.

runtime.json과 atlas.png가 같은 출력에서 내려받은 파일인지 확인하세요. 여러 출력의 파일을 섞지 말고 같은 출력 항목에서 두 파일을 다시 받아 선택하세요.
