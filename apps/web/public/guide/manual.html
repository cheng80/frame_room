작업 공간 · 어디서 무엇을 하나요?

왼쪽 라이브러리, 중앙 캔버스와 아래 재생 순서, 오른쪽 속성을 함께 사용합니다. 자료 준비 도구는 편집기 위에 창으로 열립니다.

현재 후보와 현재 슬롯 구분하기

후보는 추출한 프레임의 목록입니다. 슬롯은 그 후보를 동작의 재생 순서에 넣은 자리입니다. 같은 후보를 여러 슬롯에 넣고 서로 다른 시간과 변형을 줄 수 있습니다.

  1. 왼쪽 동작 탭에서 편집할 동작을 선택하고, 후보 탭에서 사용할 프레임을 찾습니다.
  2. 후보를 누르면 중앙의 후보 원본을 봅니다. 순서에 추가 버튼을 눌러야 동작에 들어갑니다.
  3. 아래 재생 순서의 슬롯을 선택하면 오른쪽 슬롯·픽셀 속성으로 편집합니다. 중앙의 재생 순서와 후보 원본 전환을 확인하세요.

후보 번호는 목록의 순번입니다. 품질 순위나 앱의 추천 점수가 아닙니다.

도구 창과 좁은 화면 사용하기

상단의 자료 가져오기·외형 기준·AI 동작 생성·프레임 나누기·크기·발 정렬을 열어 필요한 작업만 수행합니다.

  1. 편집할 후보나 슬롯을 선택한 뒤 필요한 도구를 엽니다. 프레임 나누기와 정렬은 메인 선택에 연결된 이미지·후보를 먼저 보여줄 수 있습니다.
  2. 도구의 이미지와 설정은 따로 스크롤합니다. 좁은 창에서는 미리보기/설정 또는 후보 보기/좌표·배율 버튼으로 영역을 전환합니다.
  3. 편집기로 돌아가기 또는 닫기를 눌러 메인 화면으로 돌아옵니다. 좁은 메인 화면은 라이브러리·캔버스·속성 버튼으로 전환합니다.

도구를 닫는 동작은 저장 버튼을 대신하지 않습니다. 미저장 표시와 각 도구의 초안 적용·저장 버튼을 확인하세요.

다음 작업에서 이어 하기

편집기 위의 다음 작업 버튼은 선택 동작에서 남은 첫 작업과 개수를 표시합니다. 오른쪽 다음 작업 탭 안에서 목록과 자동 검사 결과를 확인합니다. 페이지 바깥으로 길게 스크롤하지 않습니다.

  1. 기준 연결, 사용 후보·앵커 승인, 미저장 초안 등 현재 상태를 확인합니다. 사용하지 않는 후보의 승인은 선택 동작의 필수 작업에 넣지 않습니다.
  2. 작업 버튼을 누르면 관련 후보·슬롯·기준·정렬·저장·출력 도구로 이동합니다. 자동 검사 결과에서는 해당 프레임·도구로 이동을 사용합니다.
  3. 변경 후에는 먼저 저장하고 후보·앵커·동작을 다시 확인하세요. 충돌이 있으면 저장 충돌 해결부터 진행합니다.

수동 승인 조건을 만족해도 자동 경고가 남을 수 있습니다. 자동 검사는 예술적 품질을 보장하지 않습니다.

제작 이력과 후보 묶음

후보 탭은 기록으로 연결된 추출 실행별로 후보를 묶습니다. 원본 자료, 생성 제공자·모델과 작업 ID, 추출 실행, 클립 사용처를 확인할 수 있습니다.

  1. 추출 실행 묶음을 펼치고 원본을 눌러 프레임 나누기에서 해당 자료를 확인합니다.
  2. 후보의 출처·사용처를 펼치면 원본에서 파생된 경로와 추출 영역이 나옵니다. 같은 후보를 반복 사용한 슬롯도 각각 표시합니다.
  3. 동작 이름·슬롯 이동 버튼을 누르면 그 동작의 해당 슬롯이 선택됩니다. 아래 생성·추출 실행 기록에서 과거 실행도 확인합니다.

기록으로 연결할 수 없는 실행은 추출 실행 연결 미기록으로 표시합니다. 파일명·시각·번호만으로 계보나 추천 순위를 만들지 않습니다.

프로젝트와 자료 가져오기

프로젝트 하나를 폴더 하나로 관리합니다. 원본·편집 이력·출력을 함께 보관하고, 폴더를 복사하거나 옮긴 뒤 다시 열 수 있습니다.

새 프로젝트와 저장 위치 정하기

새 프로젝트에서 이름과 저장 위치를 정합니다. 기본 셀 크기는 출력 프레임의 작업 공간이며 가져올 이미지의 크기와 같을 필요는 없습니다.

  1. 프로젝트 목록에서 새 프로젝트를 누르고 프로젝트 이름·캐릭터 이름을 입력합니다.
  2. 저장할 부모 폴더 (선택)의 폴더 선택을 누르거나 전체 경로를 직접 입력합니다. 비우면 앱의 기본 프로젝트 위치를 사용하며, 지정한 위치 안에 새 프로젝트 폴더를 만듭니다.
  3. 기본 셀 너비·높이를 정해 프로젝트 만들기를 누릅니다. 목록에서 폴더 경로와 연결 상태를 확인하고, 폴더 위치로 Finder 또는 탐색기에서 열 수 있습니다.

프로젝트 폴더에 무엇이 들어 있나요?

project.json은 프로젝트 식별 정보, project.sqlite3는 현재 편집 상태와 모든 저장 이력·작업·출력 기록을 보관합니다. assets/와 videos/에는 실제 이미지·영상, jobs/와 outputs/에는 작업 중간 파일과 결과가 들어 있습니다.

  1. 리소스는 프로젝트 폴더 기준 상대 경로로 연결됩니다. project.sqlite3 하나만 옮기지 말고 하위 폴더를 포함한 전체 프로젝트 폴더를 보관하세요.
  2. 앱 공용 app.sqlite3는 등록 목록·작업 인덱스입니다. 프로젝트를 옮길 때 함께 복사할 필요가 없습니다.
  3. 미저장 편집 초안은 브라우저에 보관됩니다. 전체 폴더에 포함하려면 먼저 편집을 저장하고 저장됨 표시를 확인하세요.

기존 프로젝트 폴더 열기

프로젝트 폴더 열기로 원본·저장된 편집 이력·출력을 함께 불러옵니다. 폴더를 여는 동작은 AI 생성을 요청하거나 과거의 대기·실행 중 작업을 자동 재실행하지 않습니다.

  1. 프로젝트 목록에서 프로젝트 폴더 열기를 누른 뒤 폴더 선택으로 프로젝트 폴더를 고릅니다.
  2. 선택창을 사용할 수 없으면 프로젝트 폴더 경로에 전체 경로를 직접 입력합니다. 폴더 안의 project.json 또는 project.sqlite3 경로도 사용할 수 있습니다.
  3. 폴더 열기를 눌러 등록하고 편집 상태를 확인합니다. 이미 등록된 프로젝트는 목록에서 다시 열 수 있습니다.

같은 프로젝트 ID의 다른 폴더가 이미 등록돼 있으면 열 수 없습니다. 기존 등록을 목록에서 제거한 뒤 새 위치를 여세요. 사본을 동시에 작업하려면 이력·백업의 새 프로젝트로 복제 또는 ZIP 백업 복원을 사용합니다.

전체 폴더 복사·이동·이름 변경

원본, 편집 이력과 과거 출력까지 함께 백업하려면 전체 프로젝트 폴더를 복사합니다. 폴더 복사본은 기존 프로젝트 ID를 유지합니다.

  1. 편집을 저장하고 진행 중인 작업이 끝났는지 확인합니다. 폴더 위치를 눌러 Finder 또는 탐색기에서 프로젝트 폴더를 찾습니다.
  2. 백업은 하위 폴더를 포함해 전체 폴더를 복사합니다. 이동하거나 이름을 바꿀 때는 먼저 앱 목록에서 제거합니다.
  3. 폴더를 옮기거나 이름을 바꾼 뒤 프로젝트 폴더 열기에서 새 경로를 선택합니다. 다른 컴퓨터에서도 전체 폴더를 복사해 같은 방식으로 열 수 있습니다.

폴더 접근 불가가 보이면 경로와 외장 디스크 연결부터 확인하세요. 앱은 사라진 원래 폴더를 자동으로 다시 만들지 않습니다.

목록에서 제거하고 다시 등록하기

목록에서 제거는 앱의 등록을 해제합니다. 프로젝트 폴더와 그 안의 SQLite, 원본·저장 이력·작업·출력 파일은 모두 유지합니다.

  1. 필요한 미저장 편집을 먼저 저장합니다. 목록 제거 시 이 브라우저의 해당 프로젝트 초안도 지워집니다.
  2. 프로젝트 행의 목록에서 제거를 누르고 이름·경로를 확인한 뒤 목록에서 제거를 눌러 확정합니다.
  3. 다시 사용할 때 프로젝트 폴더 열기로 같은 폴더를 등록합니다. 진행 작업이나 저장 버전 충돌 때문에 제거하지 못했다면 상태를 확인한 뒤 다시 시도합니다.

없는 폴더의 목록 등록 정리하기

없는 폴더 정리는 루트 폴더 자체가 사라진 등록만 찾습니다. 앱의 목록·작업 인덱스와 해당 브라우저 초안을 정리하며 실제 파일은 변경하지 않습니다.

  1. 프로젝트 목록의 없는 폴더 정리를 누릅니다. 조회된 이름과 전체 경로를 확인하고, 이동했거나 외장 디스크가 분리된 위치인지 먼저 확인합니다.
  2. 보존할 미저장 초안이 없는지 확인한 뒤 N개 등록 정리를 누릅니다. 대상이 없으면 정리할 없는 폴더가 없습니다 안내와 닫기 버튼이 표시됩니다.
  3. 폴더가 다시 생겼거나 경로·저장 버전·진행 작업 상태가 달라지면 전체 정리가 거부됩니다. 다시 확인으로 새 목록을 조회하세요. 이동한 폴더는 프로젝트 폴더 열기로 다시 등록합니다.

폴더가 존재하지만 내부 파일이 손상되거나 누락된 경우는 이 정리 대상이 아닙니다. 이 기능은 디스크 공간을 확보하거나 손상 파일을 복구하지 않습니다.

파일 선택 후 가져오기 실행하기

파일을 선택하거나 파일바에 놓는 것은 업로드 준비입니다. 선택한 파일을 가져오는 버튼을 눌러 등록을 완료합니다.

  1. 자료 가져오기에서 PNG·WebP를 하나 이상 선택합니다. 선택한 파일 목록과 화면에 표시된 파일당 크기 한도를 확인합니다.
  2. 자료 역할을 편집할 원본·외형 기준·스타일 참조·자세 참고 중에서 고르고, 가져오기 형태를 개별 이미지·규칙 격자 시트·아틀라스/수동 영역 중에서 고릅니다.
  3. 선택한 파일 가져오기를 누른 뒤 등록된 자료의 크기·역할·출처·알파 정보를 확인합니다. 시트를 프레임으로 나누는 작업은 프레임 나누기에서 진행합니다.

가져오기가 잠겨 있으면 현재 편집 초안을 먼저 저장하세요. 자료 역할을 외형 기준으로 고르는 것만으로 기준 승인이 끝나지는 않습니다.

출처와 투명도 읽기

원본, 배경 제거 결과, 추출 프레임은 자료의 출처 정보로 구별합니다. 파일명이나 이미지 모양만 보고 AI 생성 여부를 판단하지 마세요.

  1. 자료 카드에서 가져온 원본·AI 생성 원본·배경 제거 결과·추출 프레임 등의 출처 라벨을 읽습니다.
  2. 투명·반투명·불투명 픽셀 수를 확인합니다. 실제 알파 포함 표시는 투명 픽셀이 있다는 뜻이지 경계 품질이 완벽하다는 뜻은 아닙니다.

  1. 먼저 초안을 저장하고 다음 작업 또는 수동 승인 탭의 선택 동작 자동 검사 실행을 누릅니다. 검사 입력 버전과 현재 저장 버전을 비교하세요.

  3. 기준·후보·앵커 승인을 마친 후 동작 체크리스트를 확인하고 동작 수동 승인 · 초안에 적용을 누른 뒤 저장합니다. 이후 수정하면 변경 후 재확인 필요가 표시됩니다.

저장본·초안·캐시 구분하기

폴더가 있어도 쓰기 권한·여유 공간 등의 문제로 편집을 폴더에 반영하지 못할 수 있습니다. 이때 목록과 편집기 상단에는 저장됨 대신 폴더 저장 보류가 표시됩니다.

  3. 다른 창의 변경으로 저장 충돌이 나면 내 초안과 서버 최신 이력을 비교합니다. 초안 파일로 보관한 뒤 최신 버전에 다시 적용해 검토·저장하거나, 초안을 내려받고 서버 버전을 엽니다.

아닙니다. 후보는 이미지에서 추출한 프레임 목록입니다. 번호도 목록 순번입니다. 직접 비교하고 승인·거절하거나 숨기고, 사용할 후보를 재생 순서에 추가하세요.

예제 후보 7~12에 수동 승인됨이 표시되는 이유는 무엇인가요?

그 예제에서는 assistant가 후보를 확인한 뒤 수동 승인했습니다. 수동 승인됨/approved는 승인 조작으로 기록한 상태이며 앱의 자동 추천이나 미술 품질 판정 결과가 아닙니다.

이미지 생성을 8장으로 요청하면 정확히 8장이 나오나요?

이미지 생성의 프레임 수는 요청 조건이며 실제 시트 구성을 보장하지 않습니다. 결과를 확인한 뒤 추출하세요. 영상 걷기의 8장 기본 출력과는 다른 설정입니다.

후보를 눌렀는데 왜 재생되지 않나요?

후보 원본 보기는 재생 순서를 채우지 않습니다. 먼저 동작을 만들고 선택 후보를 순서에 추가하세요. 재생 순서의 슬롯이 있어야 애니메이션이 재생됩니다.

승인 대기가 계속 표시됩니다. 자동 검사를 다시 하면 되나요?

후보·앵커·동작 중 어떤 승인이 필요한지 먼저 확인하세요. 자동 검사는 수동 승인을 대신하지 않습니다. 편집으로 관련 승인이 무효화됐다면 내용을 저장하고 다시 확인한 뒤 승인해야 합니다.

캐릭터나 무기가 잘려 보여요.

먼저 후보 원본을 보세요. 원본 후보부터 잘렸다면 추출 영역을 수정해 다시 추출합니다. 후보는 온전한데 셀에서 잘리면 셀 크기·공통 배율·목표 앵커·슬롯 변형·테두리를 확인하세요. 맞춤은 화면 배율만 바꾸므로 출력 잘림을 고치지 않습니다.

투명 배경을 요청했는데 배경이 남아 있어요.

투명 요청은 결과 알파를 보장하지 않습니다. 자료의 투명 픽셀 수와 경계를 확인하세요. 균일한 단색은 별도 배경 제거 결과를 만들 수 있지만, 그려진 체크무늬나 복잡한 배경은 픽셀 보정 또는 새 이미지가 필요할 수 있습니다.

생성·가져오기·출력 버튼이 비활성화되어 있어요.

미저장 초안·처리 중 상태·연결 상태와 화면 안내를 확인하세요. 생성에는 승인 외형 기준·사용 가능한 연결·프롬프트가 필요하고, 한 프레임 재생성에는 대상 선택도 필요합니다. 출력은 내보내기 설정의 검사 항목을 모두 확인하세요.

기본 FPS를 바꿨는데 어떤 슬롯의 시간은 그대로예요.

직접 지정한 밀리초는 기본 FPS 변경에 따라 바뀌지 않습니다. 해당 슬롯의 슬롯 표시 시간을 기본 FPS 따름으로 바꾸거나 밀리초를 직접 수정하세요.

숨기기나 순서에서 제거가 원본 파일도 지우나요?

후보 숨기기는 목록 표시 상태를 바꾸며, 순서에서 제거는 선택 슬롯을 제거합니다. 후보 원본 파일을 삭제하는 동작은 아닙니다. 숨긴 후보 포함으로 목록에서 다시 찾을 수 있습니다.

저장했는데 출력 화면은 예전 모습이에요.

출력 화면은 선택한 저장 버전으로 만든 결과를 재생합니다. 현재 편집과 다른 버전 안내와 출력 버전을 확인하세요. 최신 편집을 저장·검수하고 새 출력을 만들어 열어야 반영됩니다.

연결이 끊겼을 때 페이지를 바로 새로고침해도 되나요?

미저장 초안이 있으면 가능한 경우 현재 초안을 다운로드하고 로컬 앱 실행 상태와 연결을 먼저 확인하세요. 모든 도구 입력이 복구되는 것은 아닙니다. 브라우저 데이터 삭제는 초안 보관까지 없앨 수 있습니다.

외부 접수 결과 불명이면 다시 생성을 누르면 되나요?

외부에 요청이 접수됐을 수 있어 바로 반복하면 중복 생성이 될 수 있습니다. 작업 상태·기존 산출물·제공자 측 결과를 먼저 확인한 뒤 새 요청 여부를 결정하세요. 앱은 이 상태에서 자동 재전송하지 않습니다.

파일 뷰어에서 이미지 크기나 해시가 다르다고 합니다.

runtime.json과 atlas.png가 같은 출력에서 내려받은 파일인지 확인하세요. 여러 출력의 파일을 섞지 말고 같은 출력 항목에서 두 파일을 다시 받아 선택하세요.

되돌리기로 저장 이전 버전까지 돌아갈 수 있나요?

되돌리기는 현재 미저장 편집 초안에 적용됩니다. 과거 저장 상태로 돌아가려면 이력·백업의 버전 복원을 사용하세요. 원본까지 보관하려면 저장 후 전체 프로젝트 폴더를 복사하거나 프로젝트 백업 ZIP을 만드세요.

프로젝트를 목록에서 제거하면 실제 파일도 지워지나요?

아니요. 프로젝트 폴더의 SQLite, 원본, 저장 이력과 출력 파일은 모두 남으며 프로젝트 폴더 열기로 다시 등록할 수 있습니다. 이 브라우저의 해당 미저장 초안은 지워지므로 먼저 저장하세요.

폴더를 옮긴 뒤 프로젝트를 열 수 없어요.

프로젝트 폴더 열기에서 새 폴더를 선택하거나 새 전체 경로를 입력하세요. 하위 폴더를 포함해 모두 옮겼는지 확인합니다. 같은 ID의 다른 폴더가 등록돼 있으면 기존 등록을 목록에서 제거한 뒤 새 경로를 엽니다. 폴더 이동·이름 변경은 저장과 작업 완료 후 목록에서 제거한 상태에서 진행하세요.

없는 폴더 정리에 외장 디스크의 프로젝트가 나와요.

외장 디스크가 분리되면 등록 경로의 폴더를 찾지 못할 수 있습니다. 먼저 디스크를 연결하고 다시 확인하세요. 이 기능은 확인한 목록 등록과 브라우저 초안만 정리하며 실제 파일을 삭제하지 않습니다. 나중에 폴더를 다시 열어 등록할 수 있습니다.

부위 흔들림의 새 동작으로 저장이 비활성화되어 있어요.

먼저 저장된 반복 동작으로 흔들림 미리보기를 완료하세요. 미저장 편집·저장 충돌·처리 중 상태를 해결하고, 미리보기 이후 프로젝트 버전이나 설정이 바뀌었다면 다시 미리보기합니다. 이미 저장한 결과는 중복 저장하지 않습니다.

장비가 있는데도 판단 불가이거나 여러 곳에서 검출돼요.

이 검사는 장비 이름의 의미가 아니라 지정한 색을 찾습니다. 장비에만 있는 채도 높은 색인지, 시점·좌우가 맞는지 확인하세요. 같은 색이 옷이나 피부에도 있으면 오탐할 수 있습니다. 구분할 색이 없으면 직접 검수합니다.

걷기는 8장 기본인데 설명서 재생 예제는 왜 6장인가요?

상단과 시간 조절 예제는 이전에 실제 제작한 6장 자료입니다. 현재 영상 걷기는 한 사이클 8장 기본이며 12장도 선택할 수 있습니다. 동작 보완·검사 장의 목도리 예제는 실제 8장·1,000ms 결과입니다.

장갑이나 무기의 색이 달라지면 장비 검사로 고치나요?

장비 검사는 색 복원이나 자동 수정 기능이 아닙니다. 먼저 원본 영상과 추출·마무리 결과를 비교하세요. 원본부터 생긴 간헐적 변색은 필요한 자료를 지정해 GPT 개별 보정 작업으로 처리합니다.
