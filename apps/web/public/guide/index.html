FRAME ROOM / 01

자료 준비

프로젝트에 원본 이미지와 시트를 등록합니다.

  1. 새 프로젝트를 만들거나 기존 프로젝트를 엽니다.
  2. 자료 가져오기에서 PNG/WebP를 선택하고 역할과 형태를 지정한 뒤 가져옵니다.
  3. 원본 크기와 실제 투명도 상태를 확인합니다.

여기까지 했다면

사용할 원본이 자료 목록에 저장되어 있습니다.

02
FRAME ROOM / 02

캐릭터 기준

생성·비교에 사용할 저장 기준을 고르고 특징을 적습니다.

  1. 외형 기준 탭에서 기존 저장 기준을 선택하거나 새 기준을 만듭니다.
  2. 이미지, 고정 특징, 변경 가능 특징, 방향과 보조 참조를 정리합니다.
  3. 기준을 저장합니다. 저장한 기준은 생성 요청과 비교에 바로 사용할 수 있습니다.

여기까지 했다면

현재 동작에 사용할 캐릭터 기준과 특징이 준비됐습니다.

03
FRAME ROOM / 03

동작 만들기

저장 기준을 사용해 동작 시트를 생성하거나 기존 자료를 준비합니다.

  1. 저장 기준을 확인하고 프롬프트, 요청 프레임 수, 제공자와 모델을 설정합니다.
  2. 새 후보 생성을 눌러 요청하거나 이미 준비된 시트를 자료에서 선택합니다.
  3. 생성 결과는 후보 이력으로 저장됩니다. 사용할 후보는 다음 프레임 편집에서 고릅니다.

여기까지 했다면

동작 후보 또는 가져올 시트가 준비됐습니다.

생성 요청 예시

프롬프트와 앱의 ‘요청 프레임 수’를 맞추세요. 지정한 수와 배치대로 생성됐는지는 결과에서 확인해야 합니다.

FRAME ROOM / 04

프레임 편집

원본을 프레임으로 나누고 크기·좌표·재생 순서를 조정합니다.

  1. 시트에서 프레임 후보를 추출하고 사용할 후보를 선택합니다.
  2. 셀 크기, 배율, 안전 여백과 발 또는 루트 좌표를 조정합니다. 저장 초안은 편집값을 보존합니다.
  3. 후보를 동작 순서에 넣고 슬롯별 시간과 반복을 설정한 뒤 재생해 확인합니다.

여기까지 했다면

후보의 위치·크기와 재생 순서가 원하는 동작에 맞습니다.

05
FRAME ROOM / 05

결과 확인

저장된 기준과 후보를 비교하고 기술 검사 결과와 이력을 살펴봅니다.

  1. 외형 기준과 후보를 나란히 비교하고 필요하면 확대합니다.
  2. 원하는 후보를 순서에 추가합니다. 명시적으로 제외한 후보는 숨김 표시를 조정해 다시 사용할 수 있습니다.
  3. 자동 검사는 알파·경계 등 기술 결과로 확인하고, 그림의 모양과 움직임도 재생해 살펴봅니다.

여기까지 했다면

비교 결과와 기술 상태를 확인했고, 사용할 후보가 순서에 들어 있습니다.

기술 검사와 이미지 확인자동 검사는 알파·경계 같은 기술 상태를 살펴봅니다. 그림의 특징과 움직임은 비교·재생으로 확인하세요.

내보내기

저장된 편집을 출력해 파일과 실제 재생 결과를 확인합니다.

  1. 저장 상태와 출력 전 기술 검사 안내를 확인합니다.
  2. 내보내기를 실행하고 완료된 아틀라스와 재생을 확인합니다.
  3. 필요한 PNG, runtime.json 또는 bundle.zip을 내려받습니다.

여기까지 했다면

저장 버전으로 만든 파일을 열어 사용할 수 있습니다.
