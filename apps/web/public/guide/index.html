화면 안내화면은 2026-10-13 현재 앱에서 격리 예제 프로젝트로 촬영한 실제 캡처입니다. 예제 그림은 이전에 실제 제작한 ‘하늘 해적’ 기준 그림과 6장 걷기 출력을 가져와 앱에서 다시 나눴습니다. 촬영 중에는 새 AI 생성을 하지 않았습니다. 자료·기준·생성·나누기는 각 탭 안에서, 크기·발 정렬·이력·백업·작업 센터는 별도 창에서 다룹니다.
01
FRAME ROOM / 01

자료 준비

프로젝트에 원본 이미지와 시트를 등록합니다.

  1. 프로젝트 목록에서 새 프로젝트를 만들거나 프로젝트 폴더 열기로 기존 프로젝트를 엽니다.
  2. 자료 준비 탭 파일바의 파일 선택에서 PNG/WebP를 고릅니다. 오른쪽 가져오기 설정에서 자료 역할과 가져오기 형태를 정한 뒤 선택한 N개 가져오기를 누릅니다.
  3. 등록된 자료 카드에서 원본 크기, 출처(가져온 원본 등)와 실제 알파 포함 여부를 확인합니다.

여기까지 했다면

사용할 원본이 자료 목록에 저장되어 있습니다.

02
FRAME ROOM / 02

캐릭터 기준

생성·비교에 사용할 저장 기준을 고르고 특징을 적습니다.

  1. 캐릭터 기준 탭의 외형에서 외형 기준 이미지를 고르거나, 편집할 저장 기준에서 기존 기준을 불러옵니다.
  2. 고정 특징, 변경해도 되는 특징, 가져오면 안 되는 특징과 기준 방향을 적습니다. 스타일·자세 이미지는 참조에서 지정합니다.
  3. 새 기준 저장을 누릅니다. 상단 저장이나 ⌘/Ctrl + S로는 기준이 만들어지지 않습니다. 기존 기준을 불러와 고쳐도 새 기준 번호로 저장됩니다.

여기까지 했다면

현재 동작에 사용할 캐릭터 기준과 특징이 저장됐습니다.

03
FRAME ROOM / 03

동작 만들기

저장 기준으로 동작을 생성하거나 기존 시트·영상에서 프레임 후보를 만듭니다.

  1. 새로 생성하려면 이미지·영상 생성 → 이미지로 만들기에서 저장 기준, 동작과 포즈 설명, 요청 프레임 수, 제공자와 모델을 확인하고 새 후보 생성을 누릅니다.
  2. 이미 준비된 시트는 기존 이미지 나누기에서 처리할 이미지와 추출 방식(예: 규칙 격자 행·열)을 정하고 프레임 후보 추출을 누릅니다. 기존 MP4는 영상으로 만들기의 기존 영상 처리를 사용합니다.
  3. 결과는 후보 목록에 저장됩니다. 사용할 후보는 다음 프레임 편집에서 고릅니다.

여기까지 했다면

동작 후보가 후보 목록에 준비됐습니다.

04
FRAME ROOM / 04

프레임 편집

후보를 재생 순서에 넣고 시간·크기·발 위치를 맞춥니다.

  1. 라이브러리의 동작에서 새 동작을 만든 뒤 후보에서 프레임을 골라 선택 후보를 순서에 추가합니다.
  2. 아래 재생 순서의 슬롯을 선택해 슬롯 표시 시간을 정하고 재생으로 확인합니다. 기준 비교를 켜면 저장 기준과 나란히 봅니다.
  3. 제목줄의 크기·발 정렬 창에서 공통 배율·셀과 발·루트 앵커를 조정합니다. 편집 초안은 상단 저장으로 확정합니다.

여기까지 했다면

후보의 위치·크기와 재생 순서가 원하는 동작에 맞고 저장됐습니다.

FRAME ROOM / 05

결과 확인

저장된 결과를 재생하고 자동 검사 결과를 확인합니다.

  1. 결과 확인 탭에서 저장된 결과를 재생합니다. 최종 픽셀은 확정 미리보기 만들기로 확인합니다.
  2. 선택 동작 자동 검사 실행을 누릅니다. 경고마다 해당 프레임·도구로 이동을 눌러 셀 경계·알파·정렬을 점검합니다.
  3. 고칠 곳이 있으면 제목줄의 캐릭터 기준 수정·동작 다시 만들기·프레임·시간 수정·크기·발 정렬로 돌아갑니다. 이동만으로 생성하거나 데이터를 바꾸지 않습니다.

여기까지 했다면

저장 버전의 재생과 기술 검사 결과를 확인했습니다.

기술 검사와 이미지 확인자동 검사는 알파·경계 같은 기술 상태를 살펴봅니다. 그림의 특징과 움직임은 비교·재생으로 확인하세요.

FRAME ROOM / 06

내보내기

저장된 편집을 출력해 파일과 실제 재생 결과를 확인합니다.

  1. 미저장 초안과 저장 충돌이 없는지 확인한 뒤 출력 설정의 출력할 동작을 펼쳐 대상을 봅니다. 내보내기 탭을 연 뒤 만든 동작은 기본 포함되고 직접 제외한 동작은 계속 제외됩니다.
  2. 게임용 파일 출력을 누르고 완료된 출력 결과를 재생합니다.
  3. 출력 이력에서 atlas.png, runtime.json 등 필요한 파일이나 전체 파일 ZIP을 내려받습니다.

여기까지 했다면

저장 버전으로 만든 파일을 열어 사용할 수 있습니다.
