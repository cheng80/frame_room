# 보행 후보 선택과 로컬 검수

2026-10-04 승인된 단발 제작 실험용 도구. 앱의 자동 생성/선택 기능이 아니다.
실제 생성 원본·시각 관측은 `.data/experiments/walk-candidates-20261004/`의 로컬 자료다. 불필요한 비교 결과·검수 파일은 2026-10-05 사용자 요청으로 정리했다. Git clone에는 실험 입력이 없으므로 과거 비교 전체를 그대로 재실행할 수 있다고 가정하지 않는다. 로컬 입력/선택 시험은 별도로 실행할 수 있다. 공용 sprite-gen 스킬은 수정하지 않는다.

## 기준

원본을 보존하고 **기존 에디터에서 raw crop → 묶음 공통 배율 → 발 앵커 → 재생/재정렬**을 적용한 뒤 외형과 보행을 판정한다. 보정 전 bbox 높이 차이는 생성 일관성 실패의 독립 근거가 아니다. 포즈마다 bbox 키를 같게 만드는 자동 fit은 하지 않는다.

외형은 정렬 후 Idle의 주요 요소가 유지되고 같은 스타일로 보이면 통과한다. 미세 픽셀·명암·디테일 및 자연스러운 포즈 차이를 탈락 사유로 삼지 않는다. 요소 누락이나 뚜렷한 스타일 변경이 문제다. 카메라쪽/반대쪽 다리를 해부학적 좌우 또는 화면 좌우와 혼동하지 않는다. 필요한 단계가 부족하거나 식별이 불확실하면 완성 루프를 만들었다고 하지 않는다.

## 파일

- `generate_candidates.py`: 프로젝트 엔진으로 8후보씩 3회 생성. 기본은 준비만 하며 `--execute`가 실제 ChatGPT 구독 생성을 수행한다. 제출 marker가 있는 요청을 다시 호출하지 않는다.
- `observe_candidates.py`: 최초 24개 추출 후보의 블라인드 관측. `--execute --batch 1`부터 `6`까지 각각 한 번 수행 가능. 결과 파일이 있으면 재사용, 제출 중/불명확 marker는 재호출을 차단한다. 원본색 표시와 추출 결과를 함께 보며, 최종 에디터 보정 결과의 승인을 대신하지 않는다.
- `import_editor.py`: 기존 Idle 프로젝트를 별도 복사한 후 실제 raw 3장을 기존 API로 가져와 정렬한다. 초기 연결 성분의 작은 분리 조각은 삭제하지 않고 영역에 병합한다. 첫 접촉 자세의 머리끝/발바닥 기준 94px를 묶음 전체에 적용한다. 자동 발 앵커와 후보/동작 승인 상태는 대기이며, 제작 완료로 위장하지 않는다. 완료한 복사 프로젝트에는 재실행하지 않는다. 중간 실패는 저장된 project ID를 재사용해 원인과 진행 지점을 먼저 확인한다.
- `refine_editor_anchors.py`: 발 위치에 끌리던 수평 앵커를 몸통 중심의 지면 투영으로 보정한다. 배율과 원본 픽셀은 보존하며 실제 에디터 렌더의 캔버스 초과를 검사한다. 승인 상태는 대기다.
- `make_aligned_preview.py`: 보정 PNG로 비교 GIF를 만든다. 포즈를 합성하지 않는다.
- `build_review.py`: 독립 검수 HTML/숫자 비교 생성. `editor-aligned/`가 있으면 보정된 이미지와 `observations-aligned.json`만 사용한다. 원본 및 앱 데이터 수정/네트워크 호출 없음.
- `test_selection.py`: 외형 실패·불확실한 다리·누락 단계가 높은 점수만으로 승인되지 않는지, 보정된 이미지에 이전 관측이 섞이지 않는지 검사한다.
- `try_reorders.py`: 기존 후보의 선택·순서 가설을 별도 에디터 클립으로 저장하고 재생 비교를 만든다. 다리 라벨 미확정은 편집 시도를 막지 않는다. 기존 동작·원본·정렬을 보존하고, 순서 변경이 원래 렌더를 바꾸지 않았는지 확인한다. 실제 사용한 계획은 `reorder-plan.json`이며 8컷(125ms)과 5컷(200ms)을 모두 1초 주기로 비교한다.

## 검수 방식

저장된 시각 관측과 실제 후보 이미지를 로컬에서 비교하고 재생으로 확인한다. 외부 텍스트 분류 호출과 전용 인증키는 사용하지 않는다.

## 검증

```sh
engine/sprite-gen/.venv/bin/python -m unittest discover -s scripts/walk_experiment -p 'test_*.py' -v
engine/sprite-gen/.venv/bin/python -m py_compile scripts/walk_experiment/*.py
```

검수 화면/실제 에디터 확인은 기존 ego TaskSpace를 재사용한다. 다른 브라우저를 실행하지 않는다. 실제 관측 자료, 모델 결과, 보정 전 수치와 보정 후 판정을 혼합하지 않는다.
