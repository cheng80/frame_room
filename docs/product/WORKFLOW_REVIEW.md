# 제작 이력·수동 승인·다음 작업 검증

2026-10-03 KST. 승인된 작업 1~3만 구현했다. 비교 작업대·일괄 편집·새 진단 알고리즘·AI 재생성·게임 미리보기·후보 추천은 추가하지 않았다.

## 구현

- 후보 라이브러리는 실제 추출 실행별로 묶으며 원본 계보, 생성 제공자·모델·작업 ID, 추출 시각·입력 버전, 사용 중인 클립과 슬롯을 표시한다. 원본은 추출 도구로, 사용처는 정확한 슬롯으로 이동한다.
- 기존 추출의 `result.savedRevision`과 직전 불변 스냅샷이 있고 결과 등록 사유·프로젝트 ID가 일치할 때만 새 후보 ID 차집합을 연결한다. 새 추출은 `result.frameVersionIds`를 보관한다. 근거가 없으면 실행 연결 미기록이며 파일명·순서·시각으로 추정하지 않는다.
- 승인 상태는 `승인 대기 / 수동 승인됨 / 거절됨`, 기존 승인 후 수정은 `변경 후 재확인 필요`로 표시한다. `reviewInvalidatedReason`은 실제 이후 전환에서만 기록하고 재승인 시 제거한다. 기존 승인자를 추정하지 않는다.
- 자동 검사 보고서는 입력 저장 버전, 오류, 경고, 별도의 수동 승인 조건을 표시한다. 미저장 편집이나 버전 차이가 있으면 이전 보고서다. 낮은 알파 경고는 해당 슬롯·픽셀 도구로 이동하되 개별 좌표 미제공을 명시한다. 셀 넘침은 기존 보고서의 방향·픽셀 수를 표시하고 정렬 도구로 이동한다.
- 다음 작업은 선택 클립에서 쓰는 후보만 계산하며 기준, 후보·앵커·동작 승인, 저장·충돌, 검사, 출력으로 연결된다. 고정 뷰포트와 내부 스크롤을 유지한다.
- 서버와 초안은 공유 전환 사례로 승인 무효화를 검증한다. 승인 상태가 포함된 전체 앵커 객체의 좌표 변경도 재승인을 요구한다. 출력 게이트는 잘못된 클립 선택, 오래된 앵커, FPS/시간 불일치 등을 차단한다.
