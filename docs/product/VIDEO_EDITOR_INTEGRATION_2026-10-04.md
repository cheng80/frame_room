# 웹 에디터 영상 제작 연결

2026-10-04 KST. Grok 영상 생성·기존 MP4 가져오기·후처리·편집 후보 등록을 로컬 에디터에 연결했다. 앞서 생성한 실제 Grok MP4를 재사용했으며 **이번 구현의 추가 원격 생성 호출은 0회**다.

이후 칼·손 색 번짐 회귀를 수정했다. **아래 최초 검증 기록보다 [색 번짐 수정 기록](VIDEO_COLOR_REGRESSION_2026-10-04.md)이 최신**이다. 기준 연결과 영상용 Lanczos 축소를 복구했고, 기존 28프레임·14프레임 동작도 수정했다.

## 사용 흐름

1. 프로젝트에서 **AI 동작 생성 → 영상으로 만들기**를 연다.
2. **새 영상 생성**에서 기준 그림과 Pro/Lite·동작·방향을 선택한다. 기본 3초·480p다. 실행 버튼은 영상 1건을 요청한다.
3. 완료되면 새 동작과 후보가 등록된다. **이 동작 편집하기**로 기존 타임라인·배율·앵커·픽셀 편집을 사용한다. 새 후보·앵커·동작은 검수 대기다.
4. 이미 받은 영상은 **기존 영상 처리**에서 자동·전체·수동 구간으로 다시 추출한다. 시작 프레임은 0부터, 끝 프레임은 미포함이다. 영상 재생성 없이 처리한다. 외부 MP4도 같은 화면에서 가져온다.

실제 보행 후보를 등록한 프로젝트: [Grok 영상 · 실제 보행 검수](http://127.0.0.1:8765/#project=9717eb79-f63f-40ab-adda-149697e2c8db). 기존 앱 탭은 새로고침 후 사용한다. 사용자 요청에 따라 기존 ego TaskSpace 1의 새 탭에서 화면을 검증했다.

## 적용한 개선

- Grok 로그인 경로를 명시적으로 사용한다. API 키나 다른 제공자로 자동 전환하지 않는다.
- v2.19.0 공개 엔진의 방향 유지·장비와 손잡이 유지·Lite의 차분한 보행 문구를 반영했다. 점프·공격은 동작용 여백을 확보한다. 대기·공격 생성은 첫 그림을 마지막 프레임에도 지정한다.
- 원본 MP4를 먼저 보존한다. 배경 제거와 반복 구간 선택이 실패해도 원본 영상을 다시 처리할 수 있다.
- 걷기·달리기는 반복 구간을 검증하고, 점프는 필요하면 단일 동작으로 선택한다. 공격은 한 번 재생하는 동작으로 처리한다. 대기는 시작·끝 자세를 확인한다. 실패한 자동 선택은 수동 구간 선택으로 이어지며 자동 재생성하지 않는다.
- 원본 캔버스의 추출 프레임과 배경 제거 프레임을 모두 보존한다. 편집용 영상 후보는 첫 프레임 기준의 공통 배율과 전체 구간의 공통 영역으로 Lanczos 축소한다. 이후 편집기는 배율 1에서 시작하며, 포즈마다 높이를 맞추지 않는다. 프레임 수를 줄여도 원래 구간의 재생 시간을 유지한다.
- 생성 요청 ID를 접수 직후 저장한다. 접수가 확인된 작업은 조회부터 재개하며 POST를 반복하지 않는다. 접수 불명 요청은 재전송을 차단한다. 다운로드 완료 파일이 있으면 로그인과 원격 조회 없이 복구한다.
- MP4·프레임 출처·시간·해시가 ZIP 백업과 복원에 포함된다. 이력 복원과 작업 완료가 겹쳐도 결과에 필요한 영상·이미지·참조를 다시 연결하며 현재 편집과 활성 기준은 유지한다.
- 실행 단계 표시, 원본 영상 재생·다운로드, 후보 편집 이동을 추가했다. 숨긴 탭의 작업 상태 폴링은 쉰다.
- 화면 검증에서 발견한 작업 목록 역순을 수정했다. API의 최신순을 유지하므로 작업이 4건을 넘어도 최신 실행 작업이 표시된다.

공용 스킬이나 엔진 전체 버전을 덮어쓰지 않았다. 프로젝트 어댑터에서 필요한 기능을 연결했다. 이 문서는 최초 연결 시점의 기록이다. 다방향 묶음 생성·RIFE·주기 맞춤·색상 마무리·추가 출력은 이후 [웹 품질 보완](WEB_QUALITY_COMPLETION_2026-10-04.md)에서 적용했다. 로그인·결제 서비스와 운영 서비스의 미공개 서버 프롬프트 재현은 대상이 아니다.

브라우저의 125% 배율에서 ego 캡처가 우측·하단을 잘라 DOM 경계를 별도로 확인했다. 범위 입력과 추출 실행은 마우스 좌표 오류 후 페이지의 입력 이벤트와 버튼 클릭으로 수행했다. 선택·재생·이름 편집은 ego의 클릭·키보드로 확인했다. 추가 새로고침·MP4 업로드 화면 검사 중 사용자 제어권 전환으로 도구가 중단되어 이 두 항목은 확인하지 못했다. 마지막 작업 목록 정렬 수정은 회귀 테스트와 빌드로 검증했으며 수정 후 브라우저 재확인은 하지 않았다.

Starlette TestClient의 기존 httpx 사용 중단 예고 경고 1건이 남아 있다. 자동 반복 점수와 파일 무결성 검사가 접지·동작 자연스러움에 대한 사용자 승인을 대체하지 않는다.
