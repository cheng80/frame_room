# 웹 Spritegen의 공개 품질 보완 적용 결과

> 2026-10-06 자료 정리: 아래 조사·실험의 원본, 비교 결과와 전용 스크립트는 사용자 요청으로 삭제했다. 제품 결정·구현 기록은 보존하며 과거 경로를 현재 실행 가능한 자료로 해석하지 않는다.

2026-10-04 KST. 공개 웹 번들과 `sprite-gen v2.19.0`에서 확인한 AI 스프라이트 제작 보완을 프로젝트 에디터에 연결했다. 기반 엔진은 v2.12.1에 고정하고 영상 관련 모듈만 이식했다. 기존 Codex·추출·cyan 패치와 원본, 사용자 편집 이력을 보존했다.

방향별 기준 그림은 이미지 생성의 `영상용 기준 그림 준비`에서 프리셋으로 설명을 구성하거나 파일로 가져온 뒤 직접 선택한다. 정면·후면 보행의 중간 걸음 자세도 이 기준 그림으로 입력한다. 설명 추가와 실제 그림 생성은 별도 버튼이다. 묶음이 방향별 스틸을 숨겨서 생성하거나 대화로 제작안을 자동 구성하지는 않는다. 공개 웹의 회원·과금·공유·갤러리 및 미공개 대화 프롬프트는 이번 AI 에디터 품질 작업의 범위가 아니다.

## 걷기 색상 문제의 최종 수정

사용자가 지정한 `walk-preview-3x.gif`에는 PNG 추출 뒤 **셀 패딩 → nearest 3배 확대 → 검정에 알파 합성 → 프레임별 255색 팔레트 → 알파 임계값 128** 단계가 있었다. 편집기는 이 최종 단계를 생략한 RGBA를 사용했다. 기준 연결·축소 방식을 고치는 것만으로는 그 GIF와 같은 결과가 되지 않았다.

`video_finish.py`가 같은 마무리를 실제 후보 PNG에 저장한다. 보정 전후를 별도 자산으로 보존하고 편집·미리보기·출력이 마무리 후 후보를 공유한다. 프레임별 팔레트가 모든 영상의 시간축 색상 흔들림을 제거한다는 의미는 아니다.

실제 프로젝트 `9717eb79-f63f-40ab-adda-149697e2c8db`를 v26으로 복구했다. 기존 28·14프레임 동작의 슬롯 ID·이름·표시 시간·변형·픽셀 편집을 유지했으며 각각 1,167ms다. 이전 원본과 후보도 남아 있다.

- 원본 MP4 SHA-256: `65754461cb508c0582224a82097c91493c52f93b10db0e69f5b74cc8819acf93`.
- 사용자 지정 **실제 GIF의 28프레임 모두 색상·알파 차이 0개**. 원래 편집기의 발 앵커를 유지하므로 과거 GIF보다 오른쪽 1px·아래 2px인 배치 차이를 맞춰 비교했다. 완전 투명 픽셀의 숨은 RGB는 0으로 정규화했다.
- ego TaskSpace 1의 새 관리 탭에서 **28개 실제 편집 캔버스 RGBA 해시가 저장된 최종 PNG와 전부 일치**했다.
- 마무리 전/후 전환 시 픽셀 차이를 확인하고, 후처리 화면이 실제 최종 후보와 일치하는 것도 확인했다.

브라우저 묶음은 제출하지 않았으며, 모델×방향×동작 전체를 유료 생성한 검증은 아니다. RIFE의 실제 실행 검사는 합성 시험 영상이며 새 AI 생성 결과로 소개하지 않는다. 해당 Grok 원본의 기본 복구에는 RIFE를 사용하지 않았다.

실제 프로젝트의 수동 승인 상태는 유지했다. 따라서 저장 파일의 픽셀·시간·포맷 검사는 통과했지만 승인까지 요구하는 독립 최종 verifier는 `QA_NOT_VERIFIED`를 정상 반환한다. 남은 QA 항목은 기준·프레임·앵커·동작 승인이고 기하·파일 오류는 없다. 승인된 테스트 프로젝트의 전체 verifier와 변조 탐지 검사는 통합 테스트에서 통과했다.

RIFE 증거는 `.data/experiments/video-backport-check-20261004/real-cycle-alignment.json`에 있다.
