# 동작 보완·검사 연결 결과

> 2026-10-06 자료 정리: 아래 조사·실험의 원본, 비교 결과와 전용 스크립트는 사용자 요청으로 삭제했다. 제품 결정·구현 기록은 보존하며 과거 경로를 현재 실행 가능한 자료로 해석하지 않는다.

2026-10-06 KST. 공개 엔진의 부위 흔들림과 색 표식 장비 QA를 **속성 → 슬롯 → 동작 보완·검사**에 연결했다. 기본은 접혀 있으며 필요한 동작에서만 사용한다. 게임용 걷기 기본 8장을 유지하고, 색 복원은 사용자 결정에 따라 제품 기능에서 제외했다. 드문 변색은 필요할 때 GPT에 개별 작업을 요청한다.

현재 상태는 `git status --short --branch`, `git log -8 --oneline --decorate`로 확인한다. 이 문서의 날짜·시험 수는 기록 당시 결과이며 특정 커밋을 최신으로 고정하지 않는다.

## 동작과 보존 계약

- **부위 흔들림:** 첫 슬롯의 타원 영역을 드래그하거나 좌표로 지정하고 강도·주파수·감쇠를 조절한다. 전후 WebP와 동일 시점의 PNG 프레임을 비교한 뒤 새 동작으로 저장한다. 과도한 접힘은 강도 축소 알림 또는 중단으로 처리한다.
- **새 동작 저장:** 성공한 미리보기의 PNG를 해시 검증 후 그대로 저장한다. 이전 결과를 재계산하거나 원본에 덮어쓰지 않는다. 기존 변형·정렬·픽셀 편집은 한 번만 반영하며 슬롯별 표시 시간·반복·앵커를 유지한다. 새 후보·앵커·동작은 검수 대기다.
- **장비 좌우 검사:** 장비에만 있는 채도 높은 표식 색, 캐릭터 자신의 좌우·부위·시점·방향을 지정한다. 선택적으로 투명 기준 그림을 사용한다. 검수판·의심 사유·해당 슬롯 이동을 제공한다. 표식 미검출과 검사하지 못한 항목을 표시하며 자동 수정·승인은 하지 않는다.
- 두 기능은 저장된 프로젝트를 입력으로 쓰고 외부 생성 호출이 없다. 미저장 편집·충돌·worker 연결 상태를 확인한다. 저장 전 프로젝트/동작 버전이 달라지거나 미리보기 파일이 변조되면 적용을 거부한다. 저장 시점의 트랜잭션 안에서도 재검사한다.
- 흔들림은 4~64슬롯 반복 동작, 장비 검사는 1~64슬롯이다. 전체 60초, 셀 최대 1024×1024, 합계 16,777,216픽셀 한도를 둔다. 가변 표시 시간은 시간축에서 보간해 흔들림을 계산하며 원래 슬롯 시간을 변경하지 않는다.

API는 기존 jobs의 `preview_follow`, `apply_follow`, `check_handed`를 사용한다. [계약](../../packages/contracts/CLIP_TOOLS.md), [UI](../../apps/web/src/ClipToolsPanel.tsx), [처리 adapter](../../adapters/spritegen/clip_tools.py), [worker](../../services/worker/clip_tools_task.py).

## 실제 검증

| 범위 | 결과 |
| --- | --- |
| 앱 통합 전체 | **710 PASS**, Starlette deprecation 경고 1건 |
| 신규 동작 도구 앱 시험 | 위 수에 포함된 **58 PASS**: 처리 18, API/worker 40 |
| 웹 전체 | **325 PASS**, 이 중 신규 동작 도구 43 |
| TypeScript/Vite·설명서 | production build, HTML 및 오프라인 ZIP 생성 성공 |
| 계약·엔진 | 실행 OpenAPI 일치, 원본/승인 패치 407파일 무결성 통과 |

신규 시험은 원본 불변, 타원 밖 픽셀, 가변 시간, 접힘·잘림, 잘못된 입력, 오래된 revision, 변조된 미리보기, 중복 접수, 표식 검출/미검출, 백업·폴더 복구 후 계보·픽셀, 미저장 편집 차단과 검수 대기 결과 자동 열기를 포함한다. 엔진 소스는 이번 UI 연결에서 바꾸지 않았으며 직전 [v2.34 검증](LATEST_SKILL_UPGRADE_2026-10-06.md)의 9,211 PASS / 1 SKIP을 이번 재실행 수로 합산하지 않는다.

실제 기존 하늘 해적 영상에서 추출한 **96×128, 8장, 각 125ms** 동작의 프로젝트 폴더를 별도 복사하고 격리 인덱스에서 실행했다. 신규 유료 생성은 **0건**이다.

1. ego TaskSpace 3의 새 managed 탭에서 좌표 입력 → 흔들림 미리보기 → 새 동작 저장을 실행했다. 새 동작을 자동으로 열고 8장·1,000ms·검수 대기를 유지했다.
2. 새 동작의 8개 슬롯을 실제 `render_occurrence()`로 다시 렌더해 미리보기 PNG와 비교했다. **8/8장 전체 RGBA 일치**. 원래 2개 동작, 후보·자산·정렬 정보를 그대로 유지했다.
3. 실제 캐릭터에 없는 magenta 표식은 0/8 검출, 판단 불가로 표시했다. 이어서 여러 부위에 있는 갈색과 시험용 정면 설정을 입력해 의심 경로를 발생시켰다. 8개 의심 슬롯과 검수판을 표시하고 **슬롯 4 선택**이 실제 캔버스에 반영됐다. 이 설정은 이동 흐름 검증용이며 실제 장비 오류 판정이나 미술 승인으로 해석하지 않는다. 검사 전후 저장 revision은 6으로 같았다.
4. 사용자 원래 프로젝트·공용 SQLite 등 **1,182개 파일**은 검증 전후 해시가 동일했다. 테스트는 별도 폴더에만 결과를 저장했다.

흔들림 좌표·미리보기·저장, 패널 열기·의심 슬롯 이동은 ego 기본 조작을 사용했다. 장비 폼 입력·일부 제출은 DOM 이벤트와 `requestSubmit()`으로 실행했다. 전체 마우스·키보드·접근성 여정을 검증했다는 뜻은 아니다. 화면 캡처와 실제 이미지 로딩도 확인했다. 임시 서버는 종료하고 테스트 탭은 닫았으며 기존 사용자 비교 탭은 보존했다.

로컬 증거: `.data/experiments/clip-tools-20261006/verification.json`, `before-project.json`, `after-project.json`, `preview-ui.png`, `handed-ui.png`, 격리 프로젝트의 작업 산출물. 이 데이터와 로그·영상·SQLite는 Git에 포함하지 않는다. 다른 기기에서는 계약·테스트·설명서로 재개하며 실자료 검증이 필요하면 해당 프로젝트 폴더를 별도로 옮긴다.

## 한계

색 표식 QA는 장비의 의미나 손 자체를 인식하지 않는다. 같은 색이 여러 부위에 있으면 오탐할 수 있어 검수판 확인이 필요하다. 흔들림은 새로운 픽셀 변형이며 원본 복구·AI 재생성이 아니다. 실제 한 캐릭터에서 저장·출력 일치를 검증했으며 모든 부위의 자연스러움까지 보장하지 않는다. 외부 영상 도구 직접 실행·유료 extend/edit와 비공개 웹 서비스 전체 동등성은 이번 범위 밖이다.
