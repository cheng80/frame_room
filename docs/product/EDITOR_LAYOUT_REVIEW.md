# 에디터 작업 공간 개편

2026-10-03 KST. 긴 페이지를 따라 이동하던 편집 화면을 창 높이에 맞는 작업 공간으로 재구성했다. API·저장 revision·원본·검수 gate는 유지했다.

## 작업 맥락과 배치

- 상단: 프로젝트·저장 상태·되돌리기·저장·내보내기. 자료 → 외형 기준 → AI 생성 → 추출 → 정렬은 작업 도구로 연다.
- 왼쪽: 동작·후보 라이브러리. 후보 선택과 실제 타임라인 추가를 구분한다.
- 중앙: 편집 캔버스 또는 후보 원본. 승인 기준 비교를 켜면 기준과 결과를 나란히 표시한다.
- 아래: 재생 순서·선택·순서 이동·복제·삭제·슬롯별 표시 시간. 캔버스와 항상 함께 보인다.
- 오른쪽: 현재 슬롯·픽셀 보정·후보/동작 검수. 타임라인 선택이 검수 대상과 정렬 도구로 이어진다.
- 생성 도구: 승인 기준/고정 특징과 프롬프트/설정. 추출 도구: 원본/영역과 추출 설정. 정렬 도구: 이미지/앵커와 좌표/공통 배율. 출력 도구: 실제 출력 재생과 설정/이전 출력/다운로드.
- 자료 목록·속성·도구 설정 안에서만 스크롤한다. 작은 창에서는 패널 전환을 제공한다. 480px 이하에서는 라이브러리/캔버스/속성을 한 번에 하나씩 연다.
- 도구는 native dialog로 열어 배경 입력을 차단하고 Escape로 닫는다. 편집기를 언마운트하지 않아 동작·슬롯·비교 상태를 유지하며 열었던 버튼으로 포커스를 돌려준다.

## 증거
