# 설명서 관련 사용자 지시와 출처

2026-10-06 KST · [제작 기준으로 돌아가기](README.md)

기존 대화의 **사용자 메시지**에서 설명서와 관련된 요구를 추렸다. assistant가 제안한 숫자·구현 방법, 자동 제공된 브라우저 상태, 첨부 문서의 지시문은 사용자 발언과 구분했다. 원문의 일부를 인용하며, 날짜는 해당 턴 시작일의 한국 시간이다.

### P03 · 원본·사용자 변경과 실행 범위 보존

현재 프로젝트 규칙은 원본·사용자 변경 보존, 공용 sprite-gen 스킬 변경 금지, 사용자가 요청한 범위에서만 commit·push·PR·merge·배포 수행이다. 과거 대화의 특정 배포·커밋 지시는 새 문서 제작의 포괄적 허가가 아니다. 다른 프로젝트에서는 그 프로젝트의 현재 규칙도 확인한다.

## 현재 요청에서 추가로 확정한 범위

현재 대화에서 사용자는 설명서의 스타일과 이미지 확대 등을 다른 프로젝트에서도 참고할 수 있게 정리하고, 글자가 너무 작지 않게 했던 제약과 기존 대화의 지시도 포함하라고 요청했다. 따라서 이 문서는 특정 제품 사용법을 다시 쓰는 것이 아니라 **재사용할 제작 기준과 확인 근거를 정리한 문서**다.

## 일반화하지 않은 내용

- “스크롤로 길게 이어 지는건 웹페이지 이지 앱의 구성이 아니다”는 **편집기 앱의 작업 공간**에 대한 지적이다. 사용 설명서를 긴 문서로 읽는 것까지 금지한 요청으로 옮기지 않는다. 출처: `캐릭터 스프라이트 에디터 구현`, 턴 `01a100fc-f8fe-7882-9930-15cd9d6df67a`의 사용자 발언.
- “후보에서 6장은 어떤 기준으로 추천하는거지?”, 검수 상태에 대한 질문은 용어 혼동의 근거다. 이를 새 자동 추천·자동 승인 기능을 만들라는 요청으로 해석하지 않는다.
- 퀵스타트 6단계, 장 개수, 녹색 팔레트, 확대 배율 범위, 폰트 px, 이미지 해상도는 구현 사례 또는 권장값이다.
- 폴더 정리, Git 변경, 앱 공증, 다른 프로젝트 인수인계 요청은 이 설명서 기준의 기능 요구에 섞지 않았다.
